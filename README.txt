# 🌾 Crop Disease Detection System

A Machine Learning and Computer Vision-based project designed to detect and classify plant diseases from leaf images. This project helps farmers and agriculture enthusiasts identify crop issues early and take preventive actions.

---

## 📌 Project Overview

This repository contains the source code for a Crop Disease Detection application. The system uses a trained Machine Learning / Deep Learning model to analyze leaf images, predict potential diseases, and serve results via a user-friendly interface.

- **`models/`**: Stores the pre-trained ML/DL model files (`.h5`, `.pkl`, etc.).
- **`app.py`**: Streamlit / Flask web application to run the user interface.
- **`train.py`**: Script to train and evaluate the disease detection model.
- **`requirements.txt`**: List of all Python dependencies required to run the project.

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Python
- **Machine Learning / Deep Learning:** TensorFlow / PyTorch / OpenCV / Scikit-learn
- **Web Framework:** Streamlit / Flask
- **Data Handling:** NumPy, Pandas, Pillow
